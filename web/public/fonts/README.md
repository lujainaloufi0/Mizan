# Fonts (not included)

The web prototype uses the **Thmanyah** typeface. Its license does not allow the font files to be uploaded or shared, so they are not in this repository.

Download the family from **https://thmanyah.com**, convert or export to WOFF2, and place these files here:

```
thmanyahsans-Regular.woff2
thmanyahsans-Medium.woff2
thmanyahsans-Bold.woff2
thmanyahseriftext-Regular.woff2
thmanyahseriftext-Medium.woff2
thmanyahserifdisplay-Bold.woff2
thmanyahserifdisplay-Black.woff2
```

Without them the pages fall back to the system font. `.gitignore` keeps them out of git.
