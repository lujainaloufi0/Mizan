# Fonts (not included)

Mizan uses the **Thmanyah** typeface. Its license does not allow the font files to be uploaded or shared, so they are not in this repository.

Download the family from the official site, **https://thmanyah.com**, and place these six files here, with exactly these names:

```
ThmanyahSans-Regular.otf
ThmanyahSans-Medium.otf
ThmanyahSans-Bold.otf
ThmanyahSerifText-Regular.otf
ThmanyahSerifDisplay-Bold.otf
ThmanyahSerifDisplay-Black.otf
```

They are embedded in the compiled app (`app.json` → `expo-font`), which the license permits. `.gitignore` keeps them out of git.
